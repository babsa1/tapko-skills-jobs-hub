# TAPKO Skills & Jobs Hub

**Proof. Work. Progress.**

TAPKO is a proof-backed workforce platform for Africa—connecting job seekers, verified professionals, employers, clients, and skills development in one trusted experience.

## Core experiences

- Explainable job matching and applications
- TAPKO Passport for identity, credentials, work history, and reliability
- Verified professional discovery and service booking
- Employer vacancy and talent-shortlisting workflows
- AI-guided skills and career pathways
- Responsive green-and-gold brand experience

## Run locally

```bash
npm install
npm run dev
```

Open the local address shown in the terminal.

## Live site
